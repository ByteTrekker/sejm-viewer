{{Jak liczymy (i czego ten ranking nie mówi)}}
  1. {{Termin biegnie od daty przekazania pytania adresatowi, a nie od wpłynięcia do Sejmu — inaczej obciążalibyśmy resort opóźnieniem kancelarii. Samo to opóźnienie pokazuje osobna strona „Droga pytania”.}}
  2. {{Prolongata nie wydłuża terminu. Regulamin nie przewiduje przedłużenia; pismo o zwłoce liczymy osobno jako sygnał, nie usprawiedliwienie.}}
  3. {{Pytania skierowane do kilku adresatów naraz są wyłączone — API nie wiąże odpowiedzi z konkretnym adresatem, więc nie da się uczciwie przypisać odpowiedzialności. Liczbę wyłączonych pytań podajemy w stopce.}}
  4. {{Pytania bez odpowiedzi, którym termin jeszcze nie upłynął, nie wchodzą do mianownika.}}
  5. {{Odpowiedzi, dla których API nie podaje daty (wartownik 0000-12-30), są wyłączone z mianownika. Nie wiadomo, czy przyszły w terminie — a potraktowanie ich jak natychmiastowych dawałoby fikcyjną punktualność. Kadencja VII składa się z nich niemal w całości i dlatego nie ma rankingu.}}
  6. {{Wskaźnik milczenia (0–100) = 40% udziału po terminie + 25% udziału bez odpowiedzi + 15% udziału prolongat + 20% znormalizowanej mediany czasu odpowiedzi.}}
  7. {{Ranking mierzy terminowość, nie jakość. Odpowiedź „nie posiadamy takich danych” w 3 dni wygląda tu lepiej niż rzetelna analiza w 25 dni. Kolumna „tylko skan” to jedyne dostępne w API proxy jakości.}}
